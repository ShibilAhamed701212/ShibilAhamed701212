### 🚀 Featured Projects

* **[Library_DBMS](https://github.com/ShibilAhamed701212/Library_DBMS)** (Dec 2025 – Feb 2026)
  Flask + MySQL library management app with admin and member portals, real-time community chat (Socket.IO), gamification, membership tiers and optional AI-assisted book discovery. Built around service-repository design and role-based access control.

* **[LeaseGuardAI](https://github.com/ShibilAhamed701212/LeaseGuardAI-Agent)** (Infosys Springboard Internship 6.0)
  Lease contract analyzer: OCR extraction, LLM-based term and risk analysis (Gemini), fairness scoring, hidden-fee detection and a negotiation assistant, with privacy-first processing. React, Redis, PostgreSQL, TypeScript.

* **[VerifyIQ: AI Claim Verification](https://github.com/ShibilAhamed701212/verifyiq-ai-claim-verification)**
  Multimodal damage-claim verification. A vision model extracts facts as JSON, and deterministic Python rules decide whether photos support, contradict or are insufficient for a claim. FastAPI, Docker, OCR.

* **[Price Predictor System](https://github.com/ShibilAhamed701212/Price-Predictor-System)** (MLOps)
  End-to-end house price pipeline on the Ames Housing dataset with ZenML pipelines, MLflow tracking and deployment.

* **[climate_digital_twin](https://github.com/ShibilAhamed701212/climate_digital_twin)**
  Climate digital twin for India (Karnataka focus): ingests Open-Meteo, NASA POWER and IMD data, runs physics-informed simulation and ensemble forecasts, with a Streamlit dashboard.

* **[React Native Offline Face Auth](https://github.com/OpenForgeStack/react-native-offline-face-auth)** (OpenForgeStack)
  Offline facial authentication with an ArcFace ONNX model (512-d embeddings), liveness detection and GPS verification, built for low-resource mobile devices.

* **[voice-to-shop](https://github.com/ShibilAhamed701212/voice-to-shop)** (VoiceFix, PS-06)
  Voice-first home-service booking: an AI concierge gathers missing details, compares providers and books atomically so a slot is never double-booked.

* **[LAM-Diffusion](https://github.com/ShibilAhamed701212/lam-diffusion)**
  Anime character image synthesis with a Large Action Model planner feeding a latent diffusion model.

* **[ai-habit-tracker](https://github.com/ShibilAhamed701212/ai-habit-tracker)**
  MERN habit tracker with streaks, charts, a 90-day heatmap, AI weekly reports and a chat assistant grounded in your habit data.
